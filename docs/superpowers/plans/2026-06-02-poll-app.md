# Poll App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a LAN poll app ("what should we order / watch?") to learn Spring Boot, gRPC, Kafka, React, Zustand, and Material UI — one focused concept per task.

**Architecture:** React frontend sends grpc-web calls through an Envoy proxy to a Spring Boot gRPC service; votes flow through Kafka where a consumer tallies results and broadcasts live `TallyUpdate` messages over server-streaming gRPC to all connected clients; Zustand holds client state and drives MUI animated result bars.

**Tech Stack:** Spring Boot 3, grpc-java 1.60, Spring Kafka, Protocol Buffers 3, React 18, Vite, grpc-web, Zustand, Material UI v5, Envoy v1.28, Docker Compose

> **Learning note:** You write the implementation bodies. Tasks show you the interface (method signatures, props, store shape) so pieces connect correctly — the logic inside is yours to figure out.

## Task 2: Write poll.proto

**Learning:** Protocol Buffers syntax — messages, scalar types, `repeated`, `map`, `stream`, service/RPC declarations.

**Read first:** https://protobuf.dev/programming-guides/proto3/ — sections "Defining A Message Type", "Maps", "Defining Services".

**Files:** `proto/poll.proto`

- [ ] Create `proto/poll.proto`. Start from this shell and fill in every message and RPC yourself:

```protobuf
syntax = "proto3";

package poll;

option java_package = "com.pollapp.proto";
option java_outer_classname = "PollProto";
option java_multiple_files = true;

service PollService {
  // Five RPCs:
  // CreatePoll    — unary, host creates a poll
  // JoinPoll      — unary, voter resolves a room code into poll details
  // CastVote      — unary, voter submits/changes their vote
  // ClosePoll     — unary, host closes the poll
  // StreamResults — server-streaming, clients receive live TallyUpdate messages
}

// Messages to define (field numbers start at 1):
// CreatePollRequest:    question (string), options (repeated string)
// CreatePollResponse:   poll_id (string), room_code (string)
// JoinPollRequest:      room_code (string)
// JoinPollResponse:     poll_id (string), question (string), options (repeated string),
//                       found (bool) — false if the room code doesn't match any active poll
// CastVoteRequest:      poll_id, option, voter_id (all strings)
// CastVoteResponse:     accepted (bool)
// ClosePollRequest:     poll_id (string)
// ClosePollResponse:    closed (bool)
// StreamResultsRequest: poll_id (string)
// TallyUpdate:          counts (map<string, int32>), poll_closed (bool)
```

```java
package com.pollapp.config;

import com.pollapp.grpc.PollGrpcService;
import io.grpc.Server;
import io.grpc.netty.shaded.io.grpc.netty.NettyServerBuilder;
import jakarta.annotation.PostConstruct;
import jakarta.annotation.PreDestroy;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.context.annotation.Configuration;

import java.io.IOException;

@Configuration
public class GrpcServerConfig {

    @Value("${grpc.server.port:9090}")
    private int grpcPort;

    @Autowired
    private PollGrpcService pollGrpcService;

    private Server server;

    @PostConstruct
    public void start() throws IOException {
        server = NettyServerBuilder.forPort(grpcPort)
                .addService(pollGrpcService)
                .build()
                .start();
        System.out.println("gRPC server started on port " + grpcPort);
    }

    @PreDestroy
    public void stop() {
        if (server != null) server.shutdown();
    }
}
```
